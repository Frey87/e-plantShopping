# e-plantShopping

## Paradise Nursery Shopping Application

**e-plantShopping** is a React-based shopping cart application developed as the final project for the **Developing Front-End Apps with React** course by IBM on Coursera.

The application represents an online houseplant store called **Paradise Nursery**, where users can browse different categories of houseplants, add plants to a shopping cart, and manage their selected items.

## Features

- Landing page for Paradise Nursery
- Product listing organized by plant categories
- Plant images, names, descriptions, and prices
- Add to Cart functionality
- Dynamic shopping cart quantity
- Shopping cart powered by Redux Toolkit
- Increase and decrease item quantities
- Remove items from the shopping cart
- Dynamic item subtotals and total cart cost
- Continue Shopping navigation
- Checkout functionality
- Responsive React user interface

## Technologies
